# Проверка OpenRouter — 16 октября 2026

## Условия
Локальный компьютер владельца, отдельный диагностический HTTP-клиент PowerShell; не Vercel и не колонка. Владелец выбрал `deepseek/deepseek-v4-flash-0731`, только `deepinfra/fp8`, без переключения провайдера. Затем разрешил поиск Exa Instant и одну пробу; после отказа из Node.js отдельно разрешил один повтор через рабочий системный клиент.

Параметры поисковой пробы получены из нового обработчика: reasoning выключен, `max_tokens=240`, один серверный шаг и один поиск, до трёх результатов по 1200 символов. Для наблюдения результата использован диагностический срок 15 секунд, а не рабочий срок навыка 3,4 секунды. Автоматических повторов не было.

## Доступ с этого компьютера
- Первый POST из Node.js 22.22.3: HTTP 403 за 224 мс, без результата модели и сведений о расходе.
- Бесплатный GET проверки ключа из Node.js также возвращал 403. Проверки с другими User-Agent не решили проблему.
- Такой же GET из PowerShell: HTTP 200, ключ распознан.
- Значит, ключ не следует считать недействительным по одному отказу Node.js. Причина различия сетевых клиентов не установлена; настройки VPN/компьютера не менялись. Отказ не доказывает ошибку DeepInfra или ограничения Vercel.

## Успешный повтор через системный клиент
Синтетический вопрос: найти ближайшую гонку Формулы-1 после 16 октября 2026 года по официальному календарю.

| Показатель | Результат |
| --- | --- |
| HTTP | 200 |
| Провайдер | DeepInfra |
| Полное ожидание на компьютере | 4964 мс |
| Завершение | stop |
| Входные / выходные токены | 2572 / 117 |
| Токены рассуждений | 0 |
| Стоимость из usage.cost | $0,00714082 |
| Ссылки с выдержками | 3 |

Модель назвала Гран-при США и диапазон 23–25 октября. Полученная выдержка официального календаря подтверждает диапазон уикенда; день самой гонки отдельно в ответе не выделен. Это подтверждение работы поиска и синтеза, а не полная проверка качества ответа. Источники: [календарь Formula 1](https://www.formula1.com/en/racing/2026.html), [календарь Formula 1 для подписки](https://calendar.formula1.com/), [ESPN](https://www.espn.com/f1/schedule/_/year/2026). Их содержимое отдельно браузером в этой проверке не перепроверялось.

`usage.server_tool_use.web_search_requests` в реальном ответе отсутствовал. Нельзя трактовать это как ноль поисков: присутствовали три `url_citation` с текстовыми выдержками. Код принимает такие выдержки как подтверждение наличия источников. Ограничение одного поиска задаётся одновременно через `max_tool_calls=1` и `max_uses=1`.

## Цена и границы вывода
На момент проверки публичный каталог OpenRouter показывал для DeepInfra FP8 $0,06 за миллион входных и $0,18 за миллион выходных токенов; для Relace FP4 выход стоил $1,28/млн. Exa Instant — $0,007 за поиск плюс токены. Поэтому поиск дороже короткого ответа модели и является основной частью расхода этой пробы. Тарифы изменяемы: [модель и провайдеры](https://openrouter.ai/deepseek/deepseek-v4-flash-0731), [поиск OpenRouter](https://openrouter.ai/docs/guides/features/server-tools/web-search).

Связка работает через системный клиент, но 4964 мс превышают текущий бюджет навыка и предел Яндекса. Эти измерения включают локальный сетевой маршрут и не показывают время на Vercel. Ускорение относительно прежней связки, стабильность и качество на серии вопросов пока не подтверждены. Локальный Node.js по-прежнему не имеет подтверждённого живого доступа к OpenRouter. Публикация, смена Vercel и новые платные проверки не выполнялись.

## Локальная проверка реализации
Все 55 автоматических тестов прошли после окончательной правки. Они используют искусственные ключи и внешний HTTP; реальную скорость не измеряют. Проверены новый маршрут, память, источники, ошибки, токены, отсутствие переключений и отмена чтения ответа в пределах бюджета.

Отдельная проверка настоящего локального HTTP-сервера с искусственным внешним ответом подтвердила health, POST и перенос истории между двумя вопросами; внешних сетевых обращений не было. Процесс теста завершён, сервер закрыт. Замечание независимого обзора о пустой поисковой аннотации воспроизведено тестом и исправлено; повторный обзор не выявил замечаний.
