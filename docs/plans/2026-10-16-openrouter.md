# OpenRouter в AliceBoost — план от 16 октября 2026

Статус: завершён локально в feature/aliceboost. Публикация и переключение Vercel не выполнялись; пригодность по скорости не подтверждена.

## Результат и согласованный подход
Владелец выбрал deepseek/deepseek-v4-flash-0731 строго через deepinfra/fp8, без запасных провайдеров; затем выбрал поиск OpenRouter через Exa Instant и сначала один живой поисковый запрос. Встроенный fetch, Node.js 22+, без SDK и новых зависимостей. Применяются writing-plans, executing-plans, test-driven-development и verification-before-completion с принятой в проекте соразмерностью.

## Границы
- Явное LLM_BACKEND=openrouter; по умолчанию прежняя связка Gemini/Serper сохраняется. Само добавление ключа не переключает сервер.
- OpenRouter получает историю, текущую дату и роль «Супер Гений». Reasoning выключен, до 240 выходных токенов на шаг, одна поисковая операция Exa Instant и до трёх коротких выдержек.
- Поиск доступен модели; известные актуальные запросы и продолжения требуют поиска. Ответ без подтверждённых источников при обязательном/выполненном поиске не озвучивается как проверенный факт.
- Общий бюджет навыка прежний. Поток пользователю не передаётся: Яндексу нужен готовый JSON.
- Память остаётся state.session; Supabase, кэш, повторные запросы, новая архитектура ожидания и публикация не входят.
- Автоматические тесты используют только искусственные ключи и внешний HTTP. Живые обращения отдельно и ограниченно.

## Проверка готовности
Новая ветка не обращается к Gemini/Serper, использует только выбранного провайдера и ограниченный поиск; ключи/текст не попадают в логи, ошибки не стирают память. Все автоматические проверки проходят. Живой успех и соблюдение срока нельзя объявлять по искусственным тестам.

Проверено: 55 автоматических тестов, локальный HTTP с искусственным внешним ответом и переносом памяти, отсутствие секретов в подготовленных файлах. Независимый обзор выявил обход проверки пустой citation при отсутствующем счётчике; ошибка воспроизведена тестом и исправлена. Повторный обзор замечаний не выявил. Тестовый сервер закрыт. Живые результаты и ограничения записаны в отчёте.

Следующий шаг требует решения владельца: диагностика локального сетевого отказа Node.js либо отдельный ограниченный тест на Vercel. Дополнительные платные запросы и публикация в эту задачу не входят.
