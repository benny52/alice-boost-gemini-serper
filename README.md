# AliceBoost

Локально доработанный навык Яндекс Алисы: ответы Gemini, поиск через Serper и короткая память текущего разговора.

Основа: [alice-gemini-serper-template](https://github.com/ruslanpodzorovraw-collab/alice-gemini-serper-template), исходный коммит `3fb62838a1fcb2efcf1135d3b82319beabee4114`. Сохранены история Git и лицензия MIT. Рабочая ветка — `feature/aliceboost`.

## Локальная настройка

Нужен Node.js 22 или новее. Внешних пакетов нет, устанавливать зависимости не требуется.

1. Если файла `.env` ещё нет, скопируйте `.env.example` в `.env`. Существующий `.env` не перезаписывайте.
2. Впишите ключ Gemini из [Google AI Studio](https://aistudio.google.com/app/apikey) и ключ поиска из [Serper](https://serper.dev/).
3. При необходимости задайте в `GEMINI_MODEL` модель, доступную вашему аккаунту. Значение по умолчанию унаследовано от шаблона; доступность модели и региональные ограничения нужно проверить живым запросом.
4. Выполните `npm start`. Сервер будет слушать только локальный компьютер: `http://127.0.0.1:3000/api`.
5. Для остановки нажмите Ctrl+C.

`.env` исключён из Git. Не отправляйте ключи в сообщения и не помещайте их в исходники. Ключ Vercel для локального запуска не нужен.

Открытие `/api` в браузере проверяет только работу обработчика, а не доступность Gemini или поиска. Для диалога нужно отправлять POST в формате Яндекс Диалогов и переносить `session_state` ответа в `state.session` следующего запроса.

## Автоматическая проверка

```text
npm test
```

Тесты не загружают `.env`, используют искусственные ключи и контролируемые ответы вместо сетевых запросов. Проверяются память, выбор и контекст поиска, ошибки и отмена запросов. Наличие зелёных тестов не означает, что измерена реальная скорость Gemini/Serper.

## Поведение и ограничения

Согласованные правила и ограничения описаны в [спецификации](docs/PROJECT_SPEC.md). Главные отличия от шаблона:

- Состояние сессии укладывается в 1024 байта UTF-8; старые сообщения удаляются, слишком длинные последние сообщения сокращаются.
- Поиск понимает некоторые продолжения вопросов и даты. Например, после погоды в Москве можно уточнить «А завтра?» или «А в Санкт-Петербурге?».
- Если поиск не удался, не подключён или не нашёл сведений, навык сообщает об этом. Свежие факты не подменяются ответом без проверки.
- Таймаут охватывает и соединение, и чтение тела ответа. При отмене сохраняется ограниченный контекст.
- Команда «Забудь разговор» очищает память. После завершения сессии она также не сохраняется.

Поиск использует правила, а не полноценный анализ смысла моделью. Сложные или неоднозначные продолжения лучше формулировать полностью. Память мала; это не полный архив разговора.

## Перед будущим размещением

Размещение пока не выполнено. Сначала нужны живые замеры из выбранной среды и проверка на устройстве, настройка доступа к вебхуку и ограничений расходов. Текущий обработчик не является защищённым публичным API. Локальный сервер намеренно доступен только на 127.0.0.1.

Для Vercel сохранён обработчик `api/index.js` и конфигурация функции. После отдельного согласования можно подключить этот GitHub-репозиторий, задать переменные среды и использовать HTTPS-адрес `/api` в Яндекс Диалогах с включённым хранилищем. Локальный адрес для колонки не подходит.
