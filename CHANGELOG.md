# Изменения

## 2026-10-16 — история разговора в Supabase (локально)
- Добавлен явный режим памяти Supabase: четыре пары реплик и поисковая тема между запусками, отдельная история по навыку и пользователю либо приложению. Режим session остаётся значением по умолчанию.
- «Забудь всё» очищает сохранённую историю; revision не позволяет запоздавшему запросу затереть более новую историю или вернуть очищенный разговор.
- Чтение и запись ограничены 450/350 мс в пределах прежнего общего бюджета. Ошибки базы не прячутся: ответ сопровождается предупреждением о неподтверждённой записи; неудачная очистка не подтверждается.
- Добавлены SQL, настройка нового серверного ключа sb_secret_ и совместимость со старым service-role JWT, безопасная диагностика service=supabase.
- Проверены все 90 тестов, включая локальный HTTP-сценарий с восстановлением, изоляцией и очисткой; сервер закрыт. Независимый обзор существенных замечаний не выявил. Этот прогон использовал искусственные сервисы. Последующая разрешённая [живая проверка Supabase](docs/reports/2026-10-16-supabase-check.md) подтвердила сохранение, восстановление и защиту очистки; выявлены превышения лимитов базы и локальный HTTP 403 OpenRouter. Сквозной разговор с настоящей моделью не прошёл. Публикации и деплоя не было.

## 2026-10-16 — GPT-OSS 120B/Cerebras
- Режим OpenRouter использует GPT-OSS 120B только через Cerebras. Рассуждения low скрыты, лимит 1024 токена включает рассуждения и ответ.
- Вместо модельного вызова поискового инструмента используется предварительный Exa Instant только по локальным признакам актуальности. Уточнение сохраняет поисковый контекст, обычный вопрос и смена темы отключают плагин.
- Ближайшие события распознаются без команды «найди». Ответ запрашивается полностью на русском; ссылки и оформление очищаются, оставшиеся иностранные буквы вызывают русское сообщение об ошибке без повтора или записи неверного ответа в память.
- Бюджет времени, состояние сессии, проверка источников и безопасные логи сохранены. Gemini/Serper остаётся прежним режимом по умолчанию.
- Отдельная проба до реализации: 1824 мс, $0,00765165 через системный HTTP-клиент. Это не замер нового обработчика; [подробности](docs/reports/2026-10-16-cerebras-check.md).
- Полный прогон 61/61 и локальный HTTP прошли. По результатам обзора исправлена потеря даты в подписи ссылки; после исправления проходят все 27 проверок OpenRouter.
- Перед разрешённой публикацией повторно прошли 62 теста. Коммит eef1397 размещён на Vercel; владелец передал успешный вызов OpenRouter за 1198 мс и ответ навыка. Ограничения одного замера и неточности ответа о гонке зафиксированы в отчёте; последующих изменений программы нет.

## 2026-10-16 — локальная интеграция OpenRouter
- Добавлен явный режим OpenRouter: DeepSeek V4 Flash 0731 только через DeepInfra FP8, без запасных провайдеров. Прежний Gemini/Serper остаётся режимом по умолчанию.
- Поиск выполняется через Exa Instant с ограничением одного вызова; при обязательном или зафиксированном поиске нужны ссылки с выдержками. Рассуждения выключены, история и общий бюджет ответа сохранены.
- Добавлены роль «Супер Гений», текущая дата UTC, обработка доступа/баланса/квоты/неполного ответа и безопасная диагностика OpenRouter.
- Единственная успешная живая проба через системный клиент заняла 4964 мс и стоила $0,00714082. Ускорение и работа на Vercel не подтверждены; локальный Node.js получил HTTP 403. Подробности в [отчёте](docs/reports/2026-10-16-openrouter-check.md).
- Проверки: 55 автоматических тестов, локальный HTTP с искусственным ответом, независимый обзор. Исправлен выявленный обход проверки пустого источника.
- Изменение локальное, без push, слияния и деплоя.

## 2026-10-16 — диагностика внешних сервисов
- Для Gemini и Serper добавлены безопасные сведения о HTTP-статусе, времени, допустимом ожидании и исходе запроса. Содержимое разговора, ключи и адреса запросов не записываются.
- Сохранены прежние лимиты и ответы навыка. Пять новых проверок вместе с прежними дают 35 проходящих тестов.

## 2026-10-16 — распределение времени ответа
- Увеличено допустимое ожидание Serper; Gemini использует оставшееся время без прежнего ограничения, преждевременно отменявшего часть ответов. Общий бюджет обработчика сохранён.
- Добавлены три проверки задержек: успешный поиск с генерацией, ответ Gemini без поиска и отмена при исчерпании общего бюджета.
- Все 30 автоматических тестов проходят. Изменение отправлено в main и размещено на Vercel; [живая проверка](docs/reports/2026-10-16-vercel-timeout-check.md) подтвердила прохождение поиска, но выявила ошибки и таймауты Gemini. Стабильные содержательные ответы пока не достигнуты.

## 0.1.0 — 2026-10-15
- AliceBoost основан на исходном шаблоне с сохранением истории и лицензии.
- Память ограничена размером всего JSON состояния; поддержаны кириллица, emoji, старый формат и очистка разговора.
- Поиск учитывает даты и короткие продолжения разговора; сбои и пустая выдача больше не скрываются ответом без проверки.
- Исправлена обработка отмены HTTP, включая чтение тела ответа; прежняя память сохраняется при ошибке.
- Добавлены регрессионные проверки и локальный запуск без дополнительных пакетов.
- Изменения предназначены для локальной проверки; публикация не выполнена.
