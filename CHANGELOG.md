# Изменения

## Не опубликовано — 2026-10-16
- Увеличено допустимое ожидание Serper; Gemini использует оставшееся время без прежнего ограничения, преждевременно отменявшего часть ответов. Общий бюджет обработчика сохранён.
- Добавлены три проверки задержек: успешный поиск с генерацией, ответ Gemini без поиска и отмена при исчерпании общего бюджета.
- Все 30 автоматических тестов проходят на искусственных ответах API. Скорость этой версии на Vercel ещё не проверена.

## 0.1.0 — 2026-10-15
- AliceBoost основан на исходном шаблоне с сохранением истории и лицензии.
- Память ограничена размером всего JSON состояния; поддержаны кириллица, emoji, старый формат и очистка разговора.
- Поиск учитывает даты и короткие продолжения разговора; сбои и пустая выдача больше не скрываются ответом без проверки.
- Исправлена обработка отмены HTTP, включая чтение тела ответа; прежняя память сохраняется при ошибке.
- Добавлены регрессионные проверки и локальный запуск без дополнительных пакетов.
- Изменения предназначены для локальной проверки; публикация не выполнена.
